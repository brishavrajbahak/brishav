# Changelog

## Unreleased — V5

### Added

- A five-section proof-first experience: Hero, Work, Process, About and Contact.
- A keyboard-operable D3 project mandala with semantic controls, dialog briefings and focus return.
- A statically exported `/dashboard/loan-default/` route built from published Lending Club results.
- Exact methodology figures, the unresolved-loan exclusion reason and Brishav's status-check correction story.
- A persistent light/dark theme, themed 404, real robots and sitemap exports, and preview/production metadata modes.
- AVIF portrait variants, responsive sources, refreshed favicon/app icons and a V5 social card.
- Production content gates for the approved personal photograph and reader-tested headline.

### Changed

- Reduced the homepage from seven long cinematic chapters to five direct sections.
- Made the signal mandala the only sticky cinematic interaction.
- Converted the terminal, contact form and full dashboard into progressive enhancements.
- Replaced generic portfolio claims with Business impact, What I delivered, methodology, status and repository proof.
- Reduced initial application JavaScript to 26.2 KB gzipped against the 110 KB budget.

### Removed

- Homepage Three.js terrain, dataset globe and separate Control Room, Journey and Insights chapters.
- Long hero pinning, WebGL-dependent first paint and duplicate project-reel interfaces.

### Fixed

- Deferred Next.js hydration scripts to avoid a fast-local-server race in Cloudflare Pages previews.
- Limited scroll-driven mandala selection to desktop cinematic mode so mobile keyboard choices remain stable.
- Restored focus to the selected project after closing its briefing.
- Preserved strict inline-script CSP hashes without adding `unsafe-inline` to `script-src`.
